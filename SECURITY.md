# Security policy

## Supported version

The current `main` branch and the live GitHub Pages build receive security updates.

## Architecture and data

Signal Garden is static and client-only. Microphone samples and selected tracks stay in the browser; the app has no backend, authentication, analytics, third-party scripts, remote API calls, or persistent user data.

## Reporting a vulnerability

Use this repository’s **Security → Report a vulnerability** flow so details remain private. Please include the affected URL or file, reproduction steps, impact, and any suggested mitigation. Do not open a public issue for an unpatched vulnerability and do not include credentials, recordings, or personal data.
